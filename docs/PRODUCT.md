# RepoGuide Product

## Problem

Developers joining a project or preparing for an interview often face a large, unfamiliar codebase without a clear way to decide what to learn first. General-purpose AI can explain code, but the result can be overwhelming and does not provide a deadline-aware sequence, reliable time estimates, progress tracking, Malayalam support, or voice-based interview practice.

RepoGuide addresses that problem by turning a public GitHub repository and an interview deadline into a structured, repo-specific learning path.

## Users

### Primary users

- Kerala engineering students preparing for technical interviews.
- Learners who understand Malayalam better than English.
- Candidates interviewing with companies such as Infosys, TCS, Wipro, or startups.
- People who need fast, structured, and affordable learning support.

### Secondary users

- Indian full-stack developers onboarding to a new project.
- Freelancers learning a client codebase.
- Boot camp graduates completing take-home assignments.

## Core User Journey

1. The user pastes the URL of a public GitHub repository.
2. The user enters their interview date and daily available study time.
3. RepoGuide analyzes the repository's folder structure and key files.
4. RepoGuide creates a personalized, day-by-day roadmap with a time estimate for each topic.
5. The user works through each module using beginner-friendly explanations.
6. After each module, the user completes a three-question quiz, marks progress, and unlocks the next step after passing.
7. In the fuller product experience, the user can listen to Malayalam teaching and finish with a voice mock interview that returns a score and feedback.

## Core Features

These are the features listed as **Must Have** or **Should Have** in the blueprint:

- **GitHub URL input:** Accept a public GitHub repository link.
- **Repository analyzer:** Read the repository's folder structure and relevant files.
- **Day-by-day roadmap:** Create a repo-specific plan based on the user's deadline.
- **Time estimates:** Show how long each topic should take.
- **Simple English mode:** Provide beginner-friendly explanations.
- **Progress tracker:** Let users mark topics complete and see their progress.
- **Module quizzes:** Ask three questions after each topic to confirm understanding.

## Future Features

These are the blueprint's power features and monetization capabilities that follow the initial MVP:

- **Malayalam audio teaching:** Read each module in Malayalam.
- **Voice mock interview:** Let the user answer interview questions by voice.
- **Interview score and feedback:** Evaluate the mock interview and return detailed feedback.
- **Repository history:** Save and revisit past repository plans.
- **Team sharing:** Share roadmaps with teammates and track team progress.
- **Paid plans:** Support Free, Pro, Premium, and Team offerings through Stripe and Razorpay.
